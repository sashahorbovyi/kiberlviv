# КіберЛьвів

Навчальний вебпроєкт кіберспортивного хабу у Львові. Сайт представляє концепцію планування ігрового часу, приклад тижневого розподілу годин та добірку вправ й ігрових каналів.

## Технології

- HTML5 і семантична розмітка.
- CSS3, адаптивні сітки та CSS-анімації.
- Tailwind CSS 3.4.17, локально зібраний CSS без Play CDN.
- JavaScript для калькулятора та віджета Time.is.
- YouTube та Google Maps через iframe.

## Структура проєкту

- `index.html` — головна сторінка.
- `calculator.html` — форма калькулятора.
- `results.html` — сторінка результатів і структури плану.
- `training.html` — дев’ять модулів для CS2, Dota 2 та Valorant.
- `coaches.html` — вправи з фільтрами й добірка ігрових каналів.
- `parents.html` — гід для батьків із відео та джерелами.
- `about.html` — про проєкт, методологію та поточні можливості.
- `contact.html`, `contact-success.html` — форма звернення та завершення надсилання.
- `privacy.html`, `terms.html` — опис обробки даних і умов використання.
- `404.html` — сторінка для відсутніх адрес.
- `tips.html`, `article-*.html` — розділ порад і три статті.
- `css/` — спільні стилі, анімації та стилі додаткових сторінок.
- `js/` — локальні скрипти.
- `assets/` — зображення та іконки.

## Локальний запуск

1. Клонувати репозиторій:

   ```bash
   git clone https://github.com/sashahorbovyi/kiberlviv.git
   ```

2. Відкрити папку `kiberlviv` у Visual Studio Code.
3. Встановити розширення Live Server, якщо воно ще не встановлено.
4. Натиснути правою кнопкою на `index.html` і вибрати **Open with Live Server**.

Готовий `css/tailwind.css` включено до репозиторію: для перегляду Node.js і збірка не потрібні. Інтернет потрібен для Google Fonts, YouTube, Maps і Time.is; стилі та локальні зображення завантажуються із сайту.

## Оновлення стилів Tailwind

Після зміни утилітарних класів HTML або конфігурації теми виконайте в папці проєкту (потрібні Node.js та npm):

```bash
npm ci
npm run build:css
```

Конфігурація: `tailwind.config.cjs`; вхідний файл: `css/tailwind-input.css`; результат: `css/tailwind.css`. Додайте оновлений CSS до коміту разом зі змінами сторінок. На GitHub Pages та Netlify додаткова збірка не потрібна, поки зібраний CSS зберігається в репозиторії.

## Про проєкт і методологію

`about.html` пояснює ідею проєкту, аудиторію, порядок роботи з калькулятором, формулу та приклад заняття, дослідницьке підґрунтя й поточні можливості. Посилання «Про проєкт» є у футерах усіх сторінок; калькулятор і результати ведуть безпосередньо на `about.html#methodology`.

## Стан реалізації

Калькулятор працює у браузері у двох режимах: визначення часу за кількістю матчів і підбір повних матчів під доступний час одного заняття. Параметри можна редагувати, результат відкривається на `results.html`, план можна завантажити як текстовий файл. Вхідні значення зберігаються в параметрах посилання, без акаунта чи серверного сховища.

Формула заняття: розминка + вправи + матчі × (тривалість матчу + очікування) + аналіз + max(0, матчі − 1) × перерва. Тижневий підсумок — кількість однакових занять × час заняття. Для обмеженого бюджету підбирається найбільша кількість цілих матчів; якщо не вміщується жоден, формується заняття без матчів. Початкові значення — приклад, а не підтверджена норма чи прогноз рангу.

Сторінка «Вправи й ігрові канали» містить приклади вправ із фільтрами за грою й навичкою та окрему добірку ігрових каналів. Тренерські послуги та співпраця з проєктом не підтверджені; кнопок запису й бронювання немає. Розділ «Поради» (`tips.html`) містить три повні статті з джерелами, змістом і пов’язаними матеріалами.

## Перевірки та збірка публікації

Після `npm ci`:

```bash
npm test
npm run check:site
npm run build:site
```

Збірка оновлює Tailwind, запускає тести та перевірки посилань, створює `dist/` тільки зі сторінками й публічними ресурсами. Тести DOM перевіряють результати, фільтри вправ, завантаження плану та стани форми звернення із замоканим надсиланням. Вони не замінюють перевірку відображення, клавіатури та відео у браузері.

Netlify використовує `netlify.toml`: Node.js 24, команда `npm run build:site`, папка публікації `dist`. GitHub Pages продовжує використовувати файли кореня гілки `main`; готовий `css/tailwind.css` треба включати в коміти. `dist/` не додається в Git.

## Приймання звернень через Netlify

1. У проєкті Netlify відкрийте **Forms → Enable form detection**.
2. Виконайте нову публікацію й переконайтеся, що Netlify розпізнав форму **contact**.
3. Вручну надішліть власне тестове звернення й перевірте його в панелі Forms. Повідомлення відвідувачів не публікуються на сайті.
4. За потреби налаштуйте сповіщення в панелі Netlify. Адреса отримувача не записана у відкритий код сайту.

На Netlify JavaScript показує помилку без очищення полів і переходить на сторінку завершення лише після успішної відповіді. Без JavaScript або з GitHub Pages використовується звичайний POST на основний домен Netlify. Це також потребує активної Netlify Forms; GitHub Pages сам звернення не обробляє.

## SEO та захисні налаштування

Додано canonical, Open Graph, Twitter Card, sitemap.xml, robots.txt, схеми WebSite/Article. Результати, сторінка завершення форми та 404 мають noindex. Не блокуйте results.html у robots.txt: пошуковий робот має прочитати noindex.

`_headers` налаштовує CSP, захист від вбудовування сторінок, типів MIME та використання камери/мікрофона на Netlify. У HTML є CSP для статичної копії; політика дозволяє чинні шрифти, Time.is та iframe YouTube/Maps. GitHub Pages не застосовує `_headers`; robots.txt у підпапці репозиторію також не замінює файл у корені домену github.io.

## Перевірка розрахунку

За наявності Node.js: `node --test tests/training-model.test.cjs`. Тести перевіряють межі бюджету, цілі матчі, короткі заняття, некоректні значення та відновлення параметрів із посилання.

## Промо-відео та навігація

`assets/video/promo-background-1440p.mp4` — фонова версія з апскейлом вихідного відео 1280×720 до 2560×1440 (10 секунд, 24 кадри/с, H.264, без аудіодоріжки, близько 4,54 МБ). Масштабування Lanczos із легким підсиленням різкості; додаткові деталі не генеруються. Полегшену копію `promo-background.mp4` (960×540, 253 КБ) збережено окремо, зараз вона не підключена. На головній воно слугує декоративним фоном без звуку. `js/hero-video.js` керує відтворенням і паузою: на телефонах, за економії трафіку та зменшеного руху запуск відбувається лише кнопкою. Поза першим екраном або в прихованій вкладці відео призупиняється. Без JavaScript залишається статичне фото.

`assets/icons/logo-nav.svg` — версія логотипа зі зменшеними внутрішніми полями для шапки. `assets/icons/favicon.svg` — квадратна версія без зайвих полів для іконки вкладки. Оригінальний `Logo.svg` збережено.
