# КіберЛьвів

Навчальний вебпроєкт кіберспортивного хабу у Львові. Сайт представляє концепцію планування ігрового часу, приклад тижневого розподілу годин та каталог профілів.

## Технології

- HTML5 і семантична розмітка.
- CSS3, адаптивні сітки та CSS-анімації.
- Tailwind CSS через Play CDN.
- JavaScript для віджета Time.is.
- YouTube та Google Maps через iframe.

## Структура проєкту

- `index.html` — головна сторінка.
- `calculator.html` — форма калькулятора.
- `results.html` — сторінка результатів і структури плану.
- `coaches.html` — каталог профілів.
- `css/` — спільні стилі, анімації та стилі додаткових сторінок.
- `js/` — локальні скрипти.
- `assets/` — зображення та іконки.

## Локальний запуск

1. Клонувати репозиторій:

   ```bash
   git clone https://github.com/sashahorbovyi/kiberlviv.git
   ```

2. Відкрити папку `kiberlviv` у Visual Studio Code.
3. Встановити розширення Live Server, якщо воно ще не встановлено.
4. Натиснути правою кнопкою на `index.html` і вибрати **Open with Live Server**.

Для завантаження Tailwind CSS, Google Fonts та зовнішніх медіасервісів потрібне з'єднання з інтернетом.

## Стан реалізації

Калькулятор і сторінка результатів наразі є статичними інтерфейсами. Обчислення, збереження плану, фільтрація каталогу й надсилання запитів ще не реалізовані. Блог містить анонси матеріалів.
